# 细胞生物学 · 本地自学网页

翟中和《细胞生物学》第4版 · 教师课件逐页详解，改编为可交互的本地网页。
**课前预习 + 概念学习 + 图注解读 + 本页要点 + 本页自测 + 不懂/待问 + 全题型练习 + 错题本 + 间隔复习 + 闪卡(背/填空/写) + 模拟测验(含802整套) + 掌握度 + 术语表 + 学习计划 + 多主题 + PWA离线 + 手写 + 统计 + 备份**，纯前端、无后端、数据存本机浏览器。

> 学习闭环（配合老师讲课）：
> ① **课前**：每章顶部「📖 课前预习导览」（主线 + 带着这些问题听课）。
> ② **课中/课后**：每页「❓ 没听懂/待问」标记 + 备注；「🎯 本页自测」298 道（附逐项对错解析）；不懂的页在「🔁 今日复习」里排最前，热力图红框标记。
> ③ **记忆**：间隔复习（SM-2 精简）；「🃏 闪卡」1835 张（含 296 张掌握卡片 + 329 张配图卡：读图/英文页/本页讲解），支持 **背 / 填空 / 写** 三种回忆模式。
> ④ **应试**：「📝 模拟测验」按章节题型抽题，或一键「📄 802 整套模拟」（名解5/填空10/选择15/判断10/简答3/论述2，180 分钟）；姜益泉页含「真题试卷」索引（10 套）。
> ⑤ **习惯**：首页「🎯 学习计划」（考试倒计时 + 每日目标 + 今日进度）、「🎯 今日学习」看板（待复习/连续打卡/待问/已掌握）、每日提醒；**PWA 可安装、离线可用**。

## 如何打开

在本目录下启动一个本地服务器：

```bash
cd web
python3 -m http.server 8000
```

浏览器访问 <http://localhost:8000/>。

> 为什么需要服务器：直接双击 `index.html`（`file://`）虽然能看内容，但浏览器会把每个页面当成独立来源，
> 导致跨页的「学习总览 / 全局错题本」读不到记录。用本地服务器（或任意 http 服务）即可正常。

## 功能

- **概念学习（与 PPT 一致）**：每章按模块排列，**每个模块的讲义页之后紧跟该模块的全部考题**（选择题、判断题、填空题、简答题、论述·推导、名词解释），便于边学边练、加强记忆；讲义页左侧原图（可点开放大）、右侧完整讲解，可「标记已读」，侧栏按模块 + 题型显示目录。
- **本章知识串联图**：每章顶部「🧠 本章知识串联图」把该章知识串起来——**主线链**（可点击跳转）+ **结构树**（模块→页→要点，可勾选掌握）+ **概念关联**（每个页面标出与该页相关的其它页，如"某概念 ↔ p12"）+ **关系图**（模块级 SVG：主线流向 + 概念跨节连线，点击节点跳转）。数据由 `_tools/gen_mind.js` 从各章页面/术语自动生成（`data/mind-*.js`），零依赖、离线可用。
- **跨章知识总图**：`mindmap.html` 把 20 章按「基础/膜与运输/内膜系统与分选/骨架/周期与分裂/信号/衰老·凋亡·癌/核·分化·社会」分域，用 32 条章间关系连成一张网络（如 膜→内膜系统→膜泡→后翻译、周期→信号→癌、骨架三章相扣），点击节点进入该章；首页与各章侧栏均有入口。
- **动画演示（78 个）+ 语音讲解**：在对应讲义页的**原图下方**内嵌 HTML5 动画（不遮挡原图）。跨膜运输补充：流动镶嵌模型、膜脂不对称、两性分子自装配、膜蛋白三类型、ADP/ATP 载体、K⁺ 通道选择性滤器、三种载体（单/同向/反向）、水通道四聚体、小肠上皮吸收葡萄糖；蛋白质分选补充：真核细胞分室化、差速离心、易位子/Sec61、SRP-信号肽循环、跨膜蛋白拓扑、高尔基体极性、溶酶体质子泵；囊泡运输/后翻译补充：发动蛋白 dynamin 剪切、LDL 受体途径、Rab 循环、停靠与融合两步、叶绿体蛋白分选、核孔复合体结构；原有：Na⁺/K⁺ 泵、动作电位、水通道、协同运输、膜流动性、协助扩散、共翻译转移、N-糖基化、泛素-蛋白酶体、分子伴侣折叠、自噬、M6P 分选、网格蛋白胞吞、COPII/COPI、SNARE 融合、线粒体蛋白导入、核孔运输、过氧化物酶体、ER 质量监控；每个动画含阶段说明与「单步/重置/速度」控制（**仅单步推进，不自动播放**，便于逐阶段听清语音），并有 **🔊 语音讲解**（逐阶段中文旁白）与「🔈 本页讲解」；滚动到附近才加载。
- **练习**：
  - 选择题——点选项即时判分，显示正确答案与解析。
  - 填空题——输入答案，**模糊自动判分**（忽略空格/标点/全半角、支持逐空包含匹配）。
  - 简答题 / 论述·推导 / 名词解释——**键盘输入作答区**（自动保存到本机）+ **手写画布**，再展开参考答案与踩分点核对，用「我会 / 我不会」自评。每道简答/论述题都给出**踩分点**（按点给分的关键词），便于对照评分；并补充**比较型 / 机制型 / 实验设计型**题目（题号后标注题型），训练主观题的高阶作答能力。教材 OCR 章节（tb*）另将各章教材**思考题**整理为可作答的简答题。
- **错题本**：答错或自评「不会」自动进入；可给错因打标签（概念不清 / 记忆错误 / 理解偏差 / 审题失误 / 其他）；
  可「标记已掌握」移除。每章有抽屉式错题本，首页有跨章「全局错题本」（`wrong.html`）。
- **手写**：填空题与主观题带手写画布，支持触控笔/手指/鼠标；有橡皮、撤销、清空。
- **统计**：首页仪表盘与每章统计显示已读、答对/答错、正确率、错题数。
- **备份/恢复**：每章「数据备份」导出该章记录；首页「完整备份」导出全部章节为 JSON，换设备或清数据前请先导出。
- **导出 PDF（题目 + 我的作答）**：每章侧栏「🖨 导出PDF（题目+我的作答）」会把该章所有题目连同你的选择/判断/填空/简答输入、自评、手写笔迹一起生成可打印文档，在打印对话框里选「另存为 PDF」即可；首页有「导出全部章节」。
- **姜益泉习题集（可搜索）**：`jiangyiquan.html` 是《细胞生物学（第4版）辅导与习题集》（姜益泉）扫描件的 OCR 全文，支持关键词全文检索与按章浏览，供对照刷题（仅供个人学习，OCR 可能有少量错字）。

## 数据与隐私

所有作答、错题、错因、手写、已读记录都保存在**本机浏览器 localStorage**，不上传服务器。
清除浏览器网站数据会清空记录，请定期「完整备份」到文件。

## 目录结构

```
web/
  index.html            首页（章节卡片 + 学习总览 + 全局备份）
  ch01.html … ch05.html 各章交互页
  wrong.html            全局错题本
  assets/style.css      样式
  assets/app.js         答题引擎 / 手写 / 错题本 / 统计 / 备份
  assets/img/chNN/…     讲义页图片（JPEG，已压缩）
  data/chNN.js          各章数据（概念页 + 题目，window.CHAPTERS）
  data/manifest.js      章节清单
  _configs/             原始 PPT 配置（构建用）
  _templates/           章节页模板（构建用）
```

## 重新构建

修改 `_configs/*.json`（或重新生成 PPT 配置）后：

```bash
python3 build_web.py
```

会重新生成 `data/*.js`、压缩图片到 `assets/img/`、并输出各章节页。
