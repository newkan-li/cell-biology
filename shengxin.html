二、主线教材与资料

  • 主线陈铭《生物信息学》（第三版），科学出版社 2018——与 015012 参考书一致，体系完整，最稳妥。
  • 进阶Pevsner《Bioinformatics and Functional Genomics》——英文经典，讲清原理与工具。
  • 算法《生物信息学算法导论》(Jones & Pevzner)——想深入算法与建模时看。
  • 衔接复习初试 802 的分子生物学基础（序列、中心法则、基因组结构），因为生信的一切都建立在序列与中心法则之上。

三、必会知识模块

1. 序列与序列比对
  • 打分矩阵（PAM / BLOSUM）、空位罚分；同源、相似、一致的区别。
  • 双序列比对：Needleman–Wunsch（全局）、Smith–Waterman（局部）；动态规划思想。
  • 数据库搜索：BLAST（blastn/blastp/blastx/tblastn 的选择）、FASTA；E 值、bit score、相似性百分数的含义与判读。
  • 多序列比对：Clustal、MAFFT；保守区/保守基序；位置特异性打分（PSSM）、profile/HMM。
2. 生物数据库与检索
  • 核酸/蛋白：NCBI（GenBank）、Ensembl、UniProt（Swiss-Prot/TrEMBL）。
  • 结构：PDB；功能与通路：KEGG、GO、Reactome。
  • 会做：检索基因/蛋白条目，看懂 FASTA 头信息、注释字段、登录号。
3. 分子进化与系统发生
  • 同源、直系同源（ortholog）/旁系同源（paralog）；分子钟。
  • 距离法（UPGMA、NJ）、最大简约（MP）、最大似然（ML）、贝叶斯；自展值（bootstrap）评估可靠性。
  • 进化距离模型（Jukes–Cantor、Kimura 等）；会读系统树、判断拓扑与支持率。
4. 基因组与转录组
  • 测序技术（Sanger → NGS 二代 → 三代长读长）；读长、覆盖度、深度。
  • 基因组组装（de Bruijn 图、contig/scaffold）与注释（基因预测、ORF、非编码）。
  • 转录组：RNA-seq 流程（比对/定量→差异表达 DESeq2/edgeR）、FPKM/TPM、富集分析（GO/KEGG/GSEA）。
  • 变异检测：SNP/InDel、SNP 与疾病/群体遗传（GWAS）。
5. 结构生物信息学
  • 蛋白质二级/三级结构预测，同源建模（homology modeling）、穿针引线（threading）。
  • 结构比对与可视化（PyMOL）、分子对接（docking）基本概念；AlphaFold 的意义。
6. 统计与编程（重点）
  • 概率统计：假设检验、多重检验校正（FDR/Bonferroni）、p 值与置信区间。
  • 编程：Python（Biopython）或 R（Bioconductor）处理序列与表格；会读写 FASTA/FASTQ、批量处理。
  • Linux 命令行：常用命令、管道、脚本；会跑常用生信工具。
7. 前沿与交叉（契合 027 方向）
  • 机器学习/深度学习在组学、医学影像、药物设计中的应用（027 人工智能学院方向：智能计算医学等）。
  • 单细胞测序、多组学整合、精准医学、生物大数据与可解释 AI。

四、动手能力（面试常问「你会做什么」）

  • 熟练使用 BLAST / UniProt / NCBI / PDB / KEGG 做检索，并能解释输出（E 值、匹配长度、gap 等）。
  • 用 Python（Biopython）或 R 完成：读序列、统计碱基/GC、局部/全局比对、批量处理表格。
  • 完整走过一次小流程：下载序列 → 比对 → 建系统树 / 或 RNA-seq 差异表达 → 画图（能讲清每一步在做什么）。

五、面试准备

  • 英文自我介绍（1–2 分钟）＋ 用英文说清一个你熟悉的概念（如 BLAST、半保留复制）。
  • 读 2–3 篇目标导师的近期论文，能说出方向、方法、结论；了解学院方向（智能计算医学、AI＋组学、成像等）。
  • 准备「为什么选生物信息学 / 做过什么项目 / 会哪些工具与语言 / 读研想做什么」。
  • 复习初试细胞生物学与分子生物学核心概念，衔接生信问题（如：为什么同源比对能推断功能）。
